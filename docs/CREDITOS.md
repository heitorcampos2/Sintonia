# Créditos

- **Canais YouTube** — a forma de falar com a API do YouTube (clientes e versões, listagem de canais) segue o
  [SmartTube](https://github.com/yuliskov/SmartTube) / [MediaServiceCore](https://github.com/yuliskov/MediaServiceCore)
  (licença MIT, © yuliskov). A lista `docs/yt-clients.json` é gerada do código dele por `tools/yt_clients_from_smarttube.py`.
- **Pular patrocínios** — dados do [SponsorBlock](https://sponsor.ajay.app) (CC BY-NC-SA 4.0).
- O Sintonia não usa o token anti-robô do YouTube: a qualidade dos vídeos comuns é a que o YouTube libera sem ele.
